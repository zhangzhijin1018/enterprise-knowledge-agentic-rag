"""
Qwen3-32B 模型能力分析：

优势：
✓ 预训练数据翻倍（18T → 36T tokens）
✓ 支持思考模式，适合复杂推理
✓ 支持 119 种语言
✓ 强大的中文理解能力

✓ AIME25 数学基准从 42 分提升到 81.5 分
✓ 适合作为 Judge 模型
✓ 适合作为 Agent 核心模型

劣势：
✗ 推理速度较慢
✗ 显存需求较高（需要多卡）
✗ 成本较高（API 或部署）

推荐使用场景：
1. 作为 LLM Judge：高价值、高风险评估
2. 作为 Ground Truth 生成器：生成合成数据
3. 作为复杂合同的 Agent 执行：长文本、复杂结构

不推荐使用场景：
1. 日常快速评估（成本高）
2. 简单格式化任务（浪费资源）
3. 高频 CI 门禁检查（延迟高）

"""
何时需要微调模型：

1. 条款抽取任务
   - 当前表现：Qwen3-32B 在条款抽取上 F1 约 0.88
   - 目标表现：F1 > 0.92
   - 推荐策略：针对条款抽取进行 LoRA 微调

2. 风险识别任务
   - 当前表现：Qwen3-32B 在风险识别上 F1 约 0.82
   - 目标表现：F1 > 0.90
   - 推荐策略：针对风险识别进行 LoRA 微调 + 领域知识注入

3. 合同分类任务
   - 当前表现：Qwen3-32B 准确率约 0.94
   - 目标表现：准确率 > 0.96
   - 推荐策略：Prompt Engineering 优化 + Few-shot

推荐微调方案：

┌─────────────────────────────────────────────────────────────┐
│                    微调模型配置                               │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  基础模型：Qwen3-8B / Qwen3-14B                         │
│                                                              │

# 分层评估配置示例
TIERED_EVALUATION_CONFIG = """
# tiered_evaluation_config.yaml

# 第一层：复杂评估（使用 Qwen3-32B）
complex_evaluation:
  enabled: true
  model: Qwen3-32B
  triggers:
    - evaluation_type: "end_to_end"
    - evaluation_type: "report_quality"
    - evaluation_type: "risk_level_assessment"
    - high_value_contract: true
  criteria:
    min_contract_value: 1000000  # 合同金额 > 100万

# 第二层：标准评估（使用 Qwen3-8B）
standard_evaluation:
  enabled: true
  model: Qwen3-8B
  triggers:
    - evaluation_type: "clause_extraction"
    - evaluation_type: "contract_classification"
    - evaluation_type: "citation_check"
  criteria:
    use_fallback: true  # 当第一层不可用时

# 第三层：快速检查（规则引擎）
quick_check:
  enabled: true
  model: "rule_engine"
  triggers:
    - evaluation_type: "format_validation"
    - evaluation_type: "completeness_check"
    - evaluation_type: "exact_match"
  criteria:
    always_run: true  # 始终运行

# 评估路由规则
routing:
  - name: "high_stakes_decision"
    condition: "high_risk_contract AND high_contract_value"
    route_to: "complex_evaluation"

  - name: "routine_review"
    condition: "standard_contract AND low_risk"
    route_to: "standard_evaluation"

  - name: "quick_validation"
    condition: "check_type == 'format'"
    route_to: "quick_check"
"""
